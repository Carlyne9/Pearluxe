# Social content (Instagram + TikTok)

Goal: use the client's videos on the site so it feels like her feed.

## Options (recommended first)
1. **Original video files, self-hosted.** The client sends original exports (or downloads them from her own accounts). We compress them and host them on a video service.
   - Best quality and speed. Full design control: no platform logos, autoplay muted, custom crop.
   - Cost: manual. New videos must be added by hand.
2. **Official embeds** (Instagram/TikTok embed code)
   - Zero hosting, always up to date per post.
   - Cost: platform branding and UI inside the embed, slower, little styling control. Breaks the premium look.
3. **Automatic feed via API** (Instagram Graph API / TikTok Display API)
   - New posts appear without manual work.
   - Cost: she needs a Business/Creator account, plus app setup and review. The API returns media URLs that expire, so we still need to cache them.

**Plan:** use option 1 for the hero and product videos. Add option 3 later only if a live feed section is worth the setup.
